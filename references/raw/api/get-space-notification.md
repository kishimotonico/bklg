   
# スペースのお知らせの取得

スペースのお知らせの情報を取得します。

## 実行可能な権限

```
すべての権限

```
## メソッド

```
GET

```
## URL

```
/api/v2/space/notification

```
## レスポンス例

### ステータスライン / レスポンスヘッダ

```
HTTP/1.1 200 OK
Content-Type:application/json;charset=utf-8

```
### レスポンスボディ

```
{
    "content": "Notification",
    "updated": "2013-06-18T07:55:37Z"
}
```
